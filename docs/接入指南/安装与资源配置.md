# 安装与资源配置

[返回首页](../../README.md) · [运行示例](../../YSIFLYADLibSimple/README.md)

同一 App 在 CocoaPods、SwiftPM、手动集成中选择一种方式；不要混用版本或重复加入资源。

## 环境要求

- 最低部署目标为 iOS 11.0；SwiftPM 清单要求 Swift tools 5.9。
- 交付为静态 XCFramework，包含设备与模拟器切片。最终 App 链接需要 `-ObjC`；手动集成使用 **Do Not Embed**。
- SwiftPM 接入使用支持 Swift tools 5.9 清单的 Xcode；反馈构建问题时请提供实际 Xcode 版本与完整错误。

## 选择安装方式

选择一种安装方式，固定版本 `6.4.2`。

### CocoaPods

在 App 的 `Podfile` 使用正式版本的 Podspec URL：

```ruby
source 'https://cdn.cocoapods.org/'
platform :ios, '11.0'

target 'YourApp' do
  use_frameworks!
  pod 'YSIFLYADLibSplash',
      :podspec => 'https://raw.githubusercontent.com/LJMcarryu/YSIFLYADLibSplash_iOS/6.4.2/YSIFLYADLibSplash.podspec'
end
```

```bash
pod install
open YourApp.xcworkspace
```

该版本通过上述 URL 安装，无需依赖 CocoaPods trunk 收录。CocoaPods 自动加入资源、`-ObjC` 和所需系统库。

### Swift Package Manager

在 Xcode 的 **Add Package Dependencies** 添加仓库：

```text
https://github.com/LJMcarryu/YSIFLYADLibSplash_iOS.git
```

选择 **Exact Version** `6.4.2`，将产品 `YSIFLYADLibSplash` 加入 App target。在 App target 的 **Other Linker Flags** 保留 `$(inherited)` 并添加 `-ObjC`。SwiftPM 自动加入资源包。

### 手动集成

从 [Release 6.4.2](https://github.com/LJMcarryu/YSIFLYADLibSplash_iOS/releases/tag/6.4.2) 下载完整包 [`YSIFLYADLib-SplashOnly-6.4.2.zip`](https://github.com/LJMcarryu/YSIFLYADLibSplash_iOS/releases/download/6.4.2/YSIFLYADLib-SplashOnly-6.4.2.zip)，其中包含 framework 与资源。解压后：

1. 将 `YSIFLYADLib.xcframework` 加入 App target，选择 **Do Not Embed**。
2. 将 `YSAdvSDK.bundle` 加入 **Copy Bundle Resources**，确认最终 App 中只有一份。
3. 在 App target 的 **Other Linker Flags** 添加 `$(inherited) -ObjC`。
4. 链接 `AdSupport.framework`，将 `AppTrackingTransparency.framework` 设为 **Optional**，兼容 iOS 11～13。

三种方式均使用 `#import <YSIFLYADLib/YSIFLYADLib.h>`，不能根据依赖名称改为导入 `YSIFLYADLibSplash`。
